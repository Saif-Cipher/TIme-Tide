# Decisions

- Next.js App Router chosen for modern standard.
- Tailwind CSS v4 chosen for styling as per requirements.
- Canvas chosen over raw image tags or video for the 40-frame sequence to allow precise scroll mapping via GSAP without performance overhead.
- GSAP ScrollTrigger chosen for simple robust scroll orchestration.
- Demo data statically modeled in `data/demo-products.ts` for frontend construction before backend integration.
