# Time and Tide - Master Spec
See original TIME_AND_TIDE.md for the unedited core requirements.
This project is an affordable-premium watch marketplace for the Bangladesh market. It implements a cinematic, editorial, and dark visual language.

Key Features:
- Cinematic Canvas-based hero using 40 image frames
- GSAP-powered scroll orchestration
- Next.js App Router architecture
- Tailwind v4 styling with design tokens
