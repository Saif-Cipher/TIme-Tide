# UX Flows

## Homepage
1. User lands on site, sees dark cinematic environment and first frame of watch. Header is transparent.
2. User scrolls down, header becomes sticky dark bar.
3. Hero scrubs through 40 image frames creating a 3D reveal effect.
4. Copy overlays appear at specific scroll beats.
5. User enters normal content flow (Featured Watches, Categories, Craftsmanship).
6. Hover interactions on product cards provide subtle scale and detail reveals.
7. Footer links out to policies and future pages.
