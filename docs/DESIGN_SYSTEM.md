# Design System

## Typography
- **Display**: Bodoni Moda (Hero, statements)
- **Sans**: Inter (Body, policies)
- **Mono**: Space Grotesk (Navigation, metadata, buttons, numbers)

## Colors
- **Obsidian**: `#0B0B0A` (Primary background)
- **Carbon**: `#141413` (Secondary surfaces)
- **Warm White**: `#F3F0E8` (Primary text)
- **Stone**: `#8E8A82` (Secondary text)
- **Soft Metal**: `#B8B1A5` (Borders, muted details)
- **Champagne Gold**: `#C5A46D` (Accent / CTA emphasis)
- **Pure White**: `#FFFFFF` (High contrast moments)

## Spacing
Base unit: 4px. Scale: 4/8/12/16/24/32/48/64/80/120/160.
